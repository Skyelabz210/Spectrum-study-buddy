## Spectrum operating boundary

The academy teaches AI as a language, organization, retrieval and practice assistant. It does not treat model output as pricing, eligibility, availability, serviceability, policy or order authority.

Agents must use fictional or de-identified context and must not enter names, addresses, account numbers, phone numbers, payment data, PINs, credentials, security codes or customer screenshots.

Current Agent OS, biller, serviceability, approved product articles and live offers control.
