# CallFlow Lab v1.7.0-spectrum.0

Date: 2026-07-13

## Outcome

The connected primary Outlook calendar is now represented inside CallFlow Lab through a sanitized, source-dated onboarding brief. One Spectrum calendar item was available: the first-day new-hire orientation on Tuesday, August 11, 2026.

## Calendar content threaded into the app

- **Today:** one compact next-milestone cue with the date and arrival target.
- **Study Plan:** the complete date, time, location, schedule note, readiness checklist, confirmation instruction, provenance, and authority note.
- **My Setup:** an operational first-day checklist placed before account and benefit setup.
- **Weekly Ledger:** an auditable ingestion record with the source class, focus areas, action items, and unresolved update check.

## Source boundary

The app includes only the operational information needed for first-day readiness. It does not include the recruiter contact, mailbox address, Outlook event identifier, Outlook URL, or connector metadata. The live Outlook event and orientation email remain authoritative if instructions change.

Calendar onboarding data does not enter Quick Lookup, customer-product cards, sales prompts, or practice simulations because it is employee/admin context rather than approved product authority.

## Mobile behavior

- The landing cue is a single compact row inside the existing Today hero.
- Full schedule information lives one level down in Study Plan.
- The setup checklist uses a two-column layout only when space permits and collapses to one column on narrow screens.
- All schedule actions keep mobile touch targets at least 40 pixels high.
