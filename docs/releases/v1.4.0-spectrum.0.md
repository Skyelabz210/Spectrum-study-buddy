# CallFlow Lab v1.4.0-spectrum.0

**Release date:** 2026-07-12  
**Scope:** generated routing and voice-first sales simulation.

## Across the Spectrum

The `/across-spectrum` route is now a spoken turn-taking simulator rather than a primarily typed transcript exercise.

### Added

- Audible fictional caller openings and responses through browser speech synthesis.
- Persona-specific voice rate, pitch and browser-voice preferences with deterministic fallback selection.
- Browser microphone recognition with interim on-screen transcription and final agent turns.
- Hands-free turn exchange: caller speaks, microphone opens, agent speaks, auditor evaluates, caller answers.
- Manual microphone control, caller replay, caller-audio toggle and typing fallback.
- Private AI caller turns through the Lovable gateway when configured.
- Deterministic persona response rules when the AI gateway is unavailable or times out.
- Exact QA evidence sentences and rule reasons for every unlocked marker.
- Live auditor guidance based on the next missing behavior and selected difficulty.
- Dynamic offer board with capability-ceiling, most-logical and value-alternative lanes.
- Corpus source IDs, verification state and live-system requirements on every offer candidate.
- `aria-live` call-phase announcements and clear microphone/privacy warnings.

### Safety boundaries

- Fictional practice only; no real customer identifiers or point-of-service transactions.
- The AI caller cannot state official pricing, eligibility, availability, policy or completed order status.
- The offer board is advisory and cannot confirm an offer.
- No audio recording or transcript persistence is implemented.
- The displayed QA score is a deterministic training score, not an official Spectrum QA result.

## Routing repair

`src/routeTree.gen.ts` now follows TanStack's generated-file structure, including route-type declarations, route manifest and `_addFileTypes<FileRouteTypes>()`. Route files are the source of truth, and the configured Vite/TanStack plugin is expected to regenerate the tree during development and build.

The repository audit now checks:

- generated route-tree ownership markers;
- required route paths;
- microphone and speech-playback integration;
- AI and deterministic caller paths;
- exact QA evidence wiring;
- all persona voice profiles;
- offer-board lane integrity;
- privacy wording and legacy-content exclusions.

## Configuration

- `LOVABLE_API_KEY` enables the private AI caller.
- `LOVABLE_SIMULATOR_MODEL` optionally selects a simulator-specific model.
- Without AI configuration, deterministic caller responses remain available.
- Browser microphone support and permissions are still required for spoken agent turns.

## Verification status

Static code, route, audit and documentation wiring are committed. A successful clean `npm run check` and private-preview microphone test have not yet been observed through the connector. This release should not be treated as build-certified until those gates pass.
