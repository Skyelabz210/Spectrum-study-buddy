# CallFlow Lab v1.6.0-spectrum.0

Date: 2026-07-13

## Outcome

CallFlow Lab now uses a mobile-first workspace hierarchy. The first viewport prioritizes live-call lookup and practice. The full route set remains available through grouped navigation and the mobile More sheet.

## Reader and autoplay repair

- Speech completion, cancellation, blocked audio, unsupported browsers and runtime errors are distinct states.
- Flashcard and curriculum autoplay advance only after an utterance completes.
- Audio failure stops autoplay on the current card or lesson and exposes a repair message.
- Manual Read card and chunked page-reader controls provide deterministic retry paths.
- Across the Spectrum includes a guide reader while caller playback remains a separate call control.

## Mobile UX

- Compact Today landing workspace.
- Labeled Menu button and explicit close control.
- Menu closes after route selection.
- Bottom dock: Today, Live, Practice, Learn and More.
- Safe-area-aware dock padding and dynamic viewport sizing.
- Primary-first simulator and scenario ordering.
- Mobile call-driver selectors.
- Expandable secondary panels on long reference and workbench pages.
- Minimum touch targets and horizontally scrollable tab controls.

## Visual system

The active palette uses deep navy surfaces, Spectrum blue primary actions, cyan focus and status accents, cool-white foreground text, green success, amber verification warnings and red blocking states.
